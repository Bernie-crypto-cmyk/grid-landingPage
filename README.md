# grid-landingPage

**Description**

This is a grid landing hero page, showing stat grids with a menu toggle.

**Technologies used**

1. html
2. css
3. javascript

**What I learned**

1. how to add inline svg tags in html
2. how to add toggle button
3. how to add event Listners

**Future improvements**

1. Animate the menu panel so it slides in from the edge instead of appearing instantly
2. Count the stat numbers up from zero when the page loads
3. Trap keyboard focus inside the menu while it's open so tabbing can't escape behind it
4. Respect `prefers-reduced-motion` so any animation turns itself off for people who ask for it
5. Load the four stats from a JSON file instead of hardcoding them in your HTML
6. Turn the page into a PWA so it can be installed and viewed offline
